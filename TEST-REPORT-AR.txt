قرايتي NEXT — تقرير التحقق
==========================

تم تنفيذ الفحوصات التالية على ملفات المشروع:
[نجاح] فحص صياغة JavaScript باستخدام Node.js لجميع ملفات assets/*.js و service-worker.js.
[نجاح] تحليل index.html و admin.html بواسطة محلل HTML في Python.
[نجاح] التحقق من وجود expansion.js في index.html وفي قائمة ملفات Service Worker الأساسية.
[نجاح] تحديث اسم Cache إلى 9rayti-next-v3 لإجبار المتصفح على جلب الملفات الجديدة.
[نجاح] التحقق من وجود المستويات السبعة المحددة في ملف البيانات.
[نجاح] التحقق من سلامة أرشيف ZIP بعد إنشائه.

ما لم يمكن تأكيده في بيئة البناء:
- لم ينجح تشغيل Chromium الآلي داخل بيئة التنفيذ بسبب منع الوصول إلى صفحات localhost و file:// من مشغل المتصفح (ERR_BLOCKED_BY_ADMINISTRATOR).
- لم يمكن تنفيذ اختبار تفاعلي حقيقي على النطاق المنشور أو تأكيد نشر ملفات GitHub الحالية.
- لا يمكن اختبار API للذكاء الاصطناعي أو حسابات الأولياء لأنها غير مفعلة في هذه المرحلة.

اختبار يدوي بعد رفع الملفات:
1. افتح الموقع على الهاتف والحاسوب.
2. افتح مساحة التعلّم ثم جرّب المعلّم الذكي ومنشئ الاختبارات والألعاب ولوحة الولي والتشخيص.
3. بدّل العربية والفرنسية والإنجليزية.
4. جرّب الوضع الداكن والبحث والتصفية ولوحة الإدارة وجميع الأدوات القديمة.
5. فعّل وضع عدم الاتصال بعد أول زيارة ثم أعد تحميل الصفحة.
6. افحص عرض 320px و390px وتأكد من عدم ظهور تمرير أفقي.

مهم: الفحوصات البرمجية لا تعني أن الموقع المنشور قد تم تحديثه تلقائياً. يلزم رفع محتويات مجلد 9rayti-site إلى مستودع GitHub Pages.


اختبارات تحديث المكتبة المصوّرة
- تم توليد 190 ملف PNG والتحقق من وجودها.
- 7 مستويات ممثلة: 3p و4p و5p و6p و7b و8b و9b.
- 38 مجموعة مستوى/مادة.
- لكل مجموعة: درس مصوّر، ملخص مصوّر، اختبار تدريبي أول، اختبار مراجعة ثانٍ، وإصلاح تدريبي.
- تم تضمين واجهة التدرج داخل الأقسام وعارض الصور وأزرار التكبير والطباعة والتنزيل.
- صفحات PNG تُحمّل عند فتحها وتدخل في التخزين المؤقت بعد زيارتها؛ لا يتم تنزيل كل الصفحات تلقائياً حتى لا يثقل تحميل الموقع الأول.
- لم يُجرَ اختبار بصري حي داخل متصفح كامل في هذه البيئة؛ يلزم التحقق النهائي بعد رفع GitHub Pages، خصوصاً تشكيل الخط العربي والطباعة على الهاتف.
